# Implementation Roadmap v2

## Phase 0 — Alignment and specification

- approve repository boundaries;
- inventory existing 5SOffice data and APIs;
- define Tenant Agent journeys and acceptance criteria;
- define common identities, tenant model and evidence schema;
- establish MVP risk assessment and governance record.

**Exit:** approved MVP spec, API contracts and pilot owner.

## Phase 1 — Thin vertical slice

- web/cockpit conversational entry;
- approved 5SOffice knowledge;
- read-only room availability;
- booking proposal and explicit confirmation;
- mock or sandbox booking write;
- trace and evidence record;
- operator handoff.

**Exit:** one end-to-end demo with observable and reviewable actions.

## Phase 2 — Tenant Agent pilot

- production booking-request API;
- reception/support ticketing;
- voucher and credit preview/reservation;
- role and tenant administration;
- pilot dashboard and feedback loop.

**Exit:** controlled pilot at selected sites or tenant groups.

## Phase 3 — Administrative and Compliance capabilities

- meeting-summary workflow;
- document templates and approval;
- ISO/compliance intake and checklist;
- HQC expert escalation;
- metering and commercial packages.

## Phase 4 — Growth and Management capabilities

Only after validated demand and required integrations exist.

## Initial backlog

2. Workflow state model.

5. Booking adapter contract.
6. Voucher/credit adapter contract.
7. Evidence event schema.
8. Human-approval interface.
9. Approved knowledge publishing flow.
10. Pilot metrics dashboard.
