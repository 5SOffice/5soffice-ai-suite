# Agent Portfolio

## Capability tiers

| Agent | Primary users | Core value | Delivery priority |
|---|---|---|---|
| 5SOffice Tenant Agent | Tenants, prospects, reception, support | Complete office-service journeys | P0 |
| SME Administrative Agent | SME owners and administrators | Reduce repetitive administrative work | P1 |
| SME Compliance Agent | SME leaders, compliance staff, consultants | Structure readiness and evidence work | P1 |
| SME Growth Agent | SME sales and marketing teams | Execute repeatable campaigns | P2 |
| SME Management Agent | SME owners and managers | Create decision queues and summaries | P3 |

## Common agent lifecycle

```text
User intent
  -> identity and tenant context
  -> policy and entitlement check
  -> knowledge retrieval
  -> plan and proposed action
  -> confirmation or human approval
  -> tool execution
  -> result verification
  -> audit/evidence record
  -> user response or escalation
```

## Packaging hypothesis

- **Included tenant services:** service Q&A, selected booking and support journeys.
- **AI service credits:** metered document, meeting, marketing and compliance actions.
- **Professional escalation:** separately priced HQC or specialist review.
- **Enterprise package:** dedicated knowledge, integrations, controls and reporting.

The commercial model remains a hypothesis until pilot usage and customer interviews validate willingness to pay.
