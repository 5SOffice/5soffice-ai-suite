# ISO/IEC 27001:2022 — DEV Controls Map (Process DEV)

Purpose: Help the community understand how ISO/IEC 27001:2022 controls translate into **real project workflows** (docs + evidence), not “compliance paperwork”.

This map links each control to:
- **Where the rule lives** in this repo (policy/procedure/template)
- **What evidence looks like** (sample records)

> Note: Artefacts are intentionally stored under architecture/security/operations and GitHub workflow folders to avoid “compliance silos”.
