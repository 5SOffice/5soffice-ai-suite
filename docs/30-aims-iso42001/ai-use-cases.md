# AI Use Case Inventory

This document lists AI use cases within the AIMS scope.

For each use case we capture:
- Purpose
- Impact level
- Data types
- Automation level
- Oversight requirements
- Transparency requirements

## Examples

### LEG-001 Regulatory change explanation
- Module: Legal Compliance Tracker
- Impact: High
- Automation: Suggest
- Oversight: Required
- Transparency: Show sources and effective dates

### HR-001 CV screening assistance
- Module: HR Assistant
- Impact: Medium
- Automation: Assist
- Oversight: User confirmation required
- Transparency: Explain evaluation factors

### OPS-001 Meeting scheduling
- Module: Scheduler
- Impact: Low
- Automation: Execute with confirmation
- Oversight: Minimal
- Transparency: Indicate automated scheduling
