# Target Customers (Initial)

This document defines the initial target customers and core problems for 5SOffice AI Suite.

## Primary target
SMEs in Vietnam using serviced office / coworking services, typically lacking dedicated specialist roles (Legal/HR/Finance/Operations).

## Personas (initial)

### P1 — SME Founder / Owner
- Goals: run business, sell, hire, stay compliant, reduce admin workload
- Pain: overload, missed deadlines, unclear legal obligations, slow execution
- What AI should do: summarize impact, propose checklists, reduce operational friction

### P2 — Admin / Office Manager (SME)
- Goals: handle paperwork, contracts, scheduling, vendor coordination
- Pain: repetitive tasks, document chaos, scheduling friction
- What AI should do: document automation, scheduling, support workflows

### P3 — Accountant / Finance (SME)
- Goals: track expenses, budget, invoices, tax readiness
- Pain: messy receipts, manual tracking, uncertainty about rule changes
- What AI should do: receipt OCR, trends, budget forecasting, compliance reminders (with limitations)

### P4 — HR / Recruiter (SME, often part-time)
- Goals: hire quickly, onboard staff, manage basic HR compliance
- Pain: screening workload, inconsistent evaluation, onboarding gaps
- What AI should do: CV assistance, onboarding guides, bias-aware recommendations

## Key “Jobs to be done”
- “Help me understand what changed and what I must do next.”
- “Reduce repetitive admin work without hiring more people.”
- “Keep my company safe from avoidable compliance risks.”
- “Make my team execute faster with fewer mistakes.”

## Initial constraints
- Vietnamese language-first
- Mobile-friendly usage (SME owners/admins)
- High-impact guidance must be transparent and reviewable (human oversight)
